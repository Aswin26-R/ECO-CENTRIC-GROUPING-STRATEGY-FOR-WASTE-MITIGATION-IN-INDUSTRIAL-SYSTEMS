# ♻️ Steel Waste Management System

## Pre-Waste Analytics for Industrial Steel Waste Prediction

A full-stack machine-learning application designed to predict potential steel-industry waste **before it is generated**.

The system accepts upcoming production and raw-material details, analyzes them using a machine-learning model, and provides:

- Predicted waste type
- Waste category
- Confidence score
- Priority level
- Recommended action
- Waste-management recommendation
- Environmental note

The goal is to move waste management from a **reactive post-production process** toward a **proactive pre-waste prediction system**.

---

## 📌 Project Overview

Traditional industrial waste auditing can involve manual inspection and post-production analysis. This can be time-consuming and may introduce human error.

The proposed system allows users to enter production information before manufacturing begins and receive an estimated waste classification and recommendation.
